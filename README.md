# შექმენი გუნდის 5 წესი

**დავალების მიზანი:** გუნდური მუშაობის პრინციპების გააზრება და სამუშაო
პროცესის სწორად ორგანიზება.

## დავალების აღწერა

წარმოიდგინე, რომ მეგობრებთან ერთად პირველ საერთო პროგრამულ პროექტზე
მუშაობ. სანამ მუშაობას დაიწყებთ, საჭიროა შეთანხმდეთ წესებზე, რომლებიც
დაგეხმარებათ თანამშრომლობაში, შეცდომების თავიდან აცილებასა და საერთო
მიზნის მიღწევაში.

**დავალება:** ჩამოწერე 5 წესი, რომლებსაც შენი გუნდი პროექტზე მუშაობისას
დაიცავს.

თითოეულ წესს დაურთე მოკლე ახსნა --- რატომ არის ის მნიშვნელოვანი და რა
პრობლემის თავიდან აცილებაში დაგეხმარებათ.

## ჩაბარების ფორმატი

პასუხი ჩაწერე პირდაპირ LMS პლატფორმაზე, ტექსტური ფორმით.

1.  **წესი:** გუნდს უნდა ვაცნობოთ მნიშვნელოვანი ცვლილებების შესახებ.

    **განმარტება:** ასე გუნდის წევრები გაიგებენ, ვინ რომელ ნაწილზე
    მუშაობს და შემცირდება ერთმანეთის სამუშაოს შემთხვევით დაზიანების
    რისკი.

-   მოიფიქრე საკუთარი წესები და ნუ შემოიფარგლები მხოლოდ მაგალითებით.
-   შეგიძლია გამოიყენო Git-ისა და GitHub-ის ტექნიკური ტერმინები, თუ
